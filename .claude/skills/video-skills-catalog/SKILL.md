# Каталог видео-скилов (awesome-claude-video-skills, CC0)

Источник: https://github.com/zhuyansen/awesome-claude-video-skills — список, а не скил: сам видео не делает.
Полный текст с разделами и тестом 16 скилов — `README.md` рядом; данные — `catalog.json`
(`repo_full_name`, `description`, `kind`, `security_grade`, `stars`, `license`).

## Как пользоваться
1. Понять задачу: что за ролик (промо, объяснение, шортс, монтаж готовой съёмки, анимация), длина, формат, есть ли исходники.
2. Найти 2–3 кандидата в `catalog.json` по `kind`/описанию; брать только `security_grade: safe`, смотреть `license` (AGPL и NOASSERTION — не для платного продукта без проверки).
3. Прочитать README и SKILL.md кандидата целиком **до** установки: чужой скил — это инструкции и код, которые потом выполняются.
4. Подключить: скопировать в `.claude/skills/<имя>/` этого репозитория (не в `~/.claude` — контейнер временный), закоммитить.
5. Ключи API (ElevenLabs и т.п.) — только в переменные окружения среды, никогда в чат и не в git.

## Что рекомендует сам каталог (тест 11.10.2026, 16 скилов на одном брифе)
- Быстро получить готовый ролик со звуком: **explainroo** (vincentsch/explainroo), ~2 мин.
- Ролик с одной сквозной идеей: **onetake** (feitangyuan/onetake).
- Свой дизайн в Remotion: **remotion-dev/skills**.
- Для простого промо скил может и не понадобиться: Claude Code без скила тоже проходит все проверки.

Монтаж готовой съёмки (видеоблог) — уже подключён скил **video-use** (`.claude/skills/video-use`).
