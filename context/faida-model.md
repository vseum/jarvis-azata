## Цель по деньгам (раздел 5.2)

**5–6 клиентов на Старте = 24 500–29 400 ₽/мес = мост закрыт.** Не пятьдесят.
Те же 5 клиентов создают стоимость продажи: 5 × 4 900 = 294к/год → оценка 0,6–1,2 млн ₽ при мультипликаторе 2–4×. Монетизация и подготовка к продаже — одно действие.

> Если инфраструктура (хостинг/связь) окажется существенной — планка сдвигается на +1–2 клиента. Уточнить фактическую стоимость обслуживания. [ГИПОТЕЗА]

## 🔴 Настоящее узкое место — не код и не оффер, а ИМЕНА

**Статус на 27.07: 0 установок, 0 платящих, 0 кейсов, 0 скрипта.** Названо по именам — **3** бизнеса. Нужно **20–25**.
Первая установка нужна **не ради денег, а ради фразы** «стоит там-то, вот что дало за месяц» — без кейса первый вопрос владельца «а у кого стоит?» бьёт насмерть.

**Клин (узкий, не «малый бизнес»):** халяльный общепит, магазины мусульманской одежды, кафе и барбершопы у мечетей. **Стерлитамак, Уфа, Казань.** Вход через сообщество (рычаг 9.1), конкурентам он недоступен.

## Порядок продаж: сообщество → кейс → холодный скрипт

| | Холодно со скриптом | Через сообщество |
|---|---|---|
| Конверсия | 1–3% | 20–30% |
| Контактов до 5 клиентов | 200–400 | 20–25 |
| Часов | 60–80 + скрипт | 10–15 |
| **₽ на час** | ~300–400 | **~1 600–2 400** |

Сначала сообщество даёт 3–5 клиентов и кейс → кейс делает скрипт рабочим → скрипт масштабирует. Наоборот — самый дорогой способ узнать возражения.
