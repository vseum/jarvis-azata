## Позвоночник

umra.ru остаётся у Азата. Давление снимаем из позиции владельца, не продажей. **Сезон едет на бесплатном привлечении, потому что бюджета нет.** Главный ресурс теперь — не деньги, а время Азата.

## 1. Сезон umra.ru — бутстрап, без бюджета

- **Уровень плана честно вниз: минимум (1500) или ниже**, рост только из реинвеста комиссии. Средний/максимум требовали 4,8–7,2 млн бюджета — их нет. Ориентир — прошлый сезон 1,09 млн net.
- **Привлечение — только бесплатное:**
  - **Инстаграм-органика (рилс)** — первичный канал трафика. Азат ведёт, 50к/мес в счёт своего долга компании.
  - **216 тёплых сделок** — реактивировать первым делом (~275к маржи без рекламы).
  - **Общинный канал (9.1: имамы, мечети, сети)** — теперь обязательный, не опциональный. Самый дешёвый доступ под нишу.
  - **Ступенчатый бюджет:** органика+тёплые → сбор комиссии → реинвест. Компаунд из своих.
- **Бесплатные рычаги маржи:** комиссия 100→110 $ (переговоры авг); хадж-выплата в рубли (2 355 ₽, сразу).
- **Открыто:** как сезон финансируется без машины — с чего живут менеджеры и реклама в декабре, если оборотных нет. Разговор с Саней.

## 2. Личный мост Азата — ПРИОРИТЕТНАЯ дыра

- Инстаграм идёт в долг, не в карман → на жизнь авг–фев: дефицит 14–24к/мес, резерв 50к (~2–3 мес), дальше пусто.
- **Решение (рекомендация): расконсервировать подряд ФЗ-152 / личную работу** — один заказ 150–300к в окне авг–сен закрывает весь личный мост. Личные деньги мимо компании (она платить не может). **[решение за Азатом]**
- Долг 3,5 млн: часть гасится инстаграмом (50к/мес → ~350к за сезон); остальное — по графику из прибыли сезона.

## 3. Приложение УМРА.РУ — вписывается в безбюджетный мир

- Ноль маржинальной стоимости, органический funnel — ровно под «нет денег, есть время». Строит стоимость и удержание.
- Роль двойная: канал сезона (инстаграм→установки→удержание→брони) + актив на будущее.
- Инженерно зелёный свет, спека v0.1 готова. Стройка в августе, заморозка на сезон.
- **Но конкурирует за августовское время** с сезон-органикой и подрядом. Все три в август = риск 4.2. **Влезает два — выбрать.**

## 4. Приоритет августовского времени (главный ресурс)

Три претендента, влезает два:
1. **Сезон-органика** (инстаграм + тёплые + община) — двигатель кассы, не опционально.
2. **Подряд 150–300к** — личный мост, тоже почти не опционально (иначе через 2–3 мес личная касса пуста).
3. **Приложение** — стоимость+удержание, но это единственное, что можно сдвинуть.
- **Лин Джарвиса:** август = сезон-органика + подряд. Приложение — сентябрь-октябрь, если останется время, либо облегчённый MVP. Не тянуть три фронта.

## 5. Снятие давления (из позиции владельца)

- **Bus factor = 1** — приоритет: бэкапы, документация, второй доступ, runbook. Пара дней. Единственное давление, что не купить.
- **Бумага по партнёрству** + прямой разговор с Саней (долг компании, оборотные, финансирование сезона). Эпизод выкупа показал: позиция неоформлена, партнёр под стрессом.
- Долг — на график сезона, не гасить продажей себя.

## 6. Реальные риски (по весу)

1. **Сезон без оборотных** — как финансировать рекламу/менеджеров в пик, если денег нет. Главный вопрос сезона.
2. **Саня под денежным стрессом** на кассе/учёте/оборотных — партнёрский риск вырос, не фон.
3. **Личная касса Азата** — непокрыта после ~2–3 мес резерва, если не взять подряд.
4. **Bus factor = 1** — не снят.
5. **Всё на времени Азата** — три фронта в август не тянутся.
