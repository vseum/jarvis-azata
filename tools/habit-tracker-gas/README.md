# От Фаджра до Витра — установка (5 минут)

Трекер без входа в Claude: страница и данные живут в твоём Google-аккаунте, отметки — в Google-таблице.

1. Открой https://script.google.com → **Новый проект**. Назови «От Фаджра до Витра».
2. Файл `Code.gs`: удали всё, вставь содержимое `Code.gs` отсюда.
3. Слева **+** → **HTML** → имя `Index` (без .html). Вставь содержимое `Index.html`.
4. Сохрани (Cmd+S). Справа сверху **Начать развертывание → Новое развертывание** → шестерёнка → **Веб-приложение**:
   - Запуск от имени: **Я**
   - Доступ: **Все** (Anyone)
   → **Развернуть** → разреши доступ (Google предупредит «приложение не проверено» → Дополнительно → Перейти). 
5. Скопируй URL веб-приложения (`https://script.google.com/macros/s/…/exec`).
6. iPhone: открой URL в Safari → Поделиться → **На экран «Домой»**. Mac: закладка или Dock.

Таблица «Трекер привычек — От Фаджра до Витра» появится в Google Диске после первого открытия.

**Обновить страницу после правок:** Развертывание → Управление развертываниями → карандаш → Версия: **Новая** → Развернуть. URL не меняется.

**Для Джарвиса:** `<URL>?format=json` отдаёт все дни JSON-ом.

Ссылка длинная и случайная, но кто её знает — может ставить отметки. Не публикуй её.
